# 🍏 MacBook Pro Setup Guide: GitHub & Project Synchronization

This guide will walk you through exactly how to connect your MacBook to the GitHub repository, allowing you to easily pull (download) the latest code, push (upload) changes, and run the M2 Max-optimized AI scripts safely.

---

## Part 1: Authenticate Your MacBook with GitHub
Since GitHub no longer allows you to push/pull code using just your account password in the terminal, the easiest and most secure method is to use the official **GitHub CLI** (Command Line Interface).

### 1. Install the GitHub CLI
Open the **Terminal** app on your MacBook and run the following command to download the software:
```bash
brew install gh
```
*(Note: If you receive a `brew: command not found` error, it means you don't have Homebrew installed. First, paste this command to install it: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`, and then run the `brew install gh` command.)*

### 2. Log In
Once installed, tell the Terminal to securely log in to your account:
```bash
gh auth login
```
The terminal will ask you a series of setup questions. Use your arrow keys to select these answers:
1. **What account do you want to log into?** `GitHub.com`
2. **What is your preferred protocol?** `HTTPS`
3. **Authenticate Git with your GitHub credentials?** `Yes`
4. **How would you like to authenticate?** `Login with a web browser`

The system will display a short security code and automatically open Safari or Chrome. Type that code into the GitHub webpage to verify your machine. **Your MacBook is now securely connected to GitHub!**

---

## Part 2: Clone the Fake News Detection Repository
Now that your Mac has permission to talk to GitHub, you can securely download the massive AI repository.

1. Open your Terminal and navigate to wherever you want to save the project (e.g., your Desktop):
   ```bash
   cd Desktop
   ```
2. Clone the repository down to your machine:
   ```bash
   git clone https://github.com/MrAjmera/Fake_News_Detection.git
   ```
3. Enter the newly downloaded project folder:
   ```bash
   cd Fake_News_Detection
   ```

---

## Part 3: Environment Setup & Running the Code

Because this project uses advanced Machine Learning libraries (like `scikit-learn` and `textblob`), you must install the dependencies on the MacBook so the Python code executes properly.

1. **Install Python Libraries:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Execute the Universal Training Script:**
   The ultimate script uses Mac-specific multiprocessing to utilize all your Apple Silicon CPU cores. Run the script:
   ```bash
   cd src
   python train_ultimate.py
   ```

### ⚠️ Important Caution for Data Scientists
The final AI model (`model_rf_ultimate.pkl`) generated by this script will likely be **over 100 Megabytes in size**. Standard GitHub will reject and block any `git push` that contains a file larger than 100MB! 

**Rule of Thumb:**
- Use `git pull` and `git push` ONLY to share the `.py` code files.
- To transfer the heavy `.pkl` models back to your Windows machine, use Google Drive, AirDrop, or a physical USB stick. Do **not** run `git add models/model_rf_ultimate.pkl`!
